## 0. 试跑前（一次性，10 分钟）

| # | 做什么 | 在哪 | 为什么 |
|---|---|---|---|
| 0.1 | **期初结转**：录"上线前冷库里各部位还有多少 kg" + **当时多少钱一斤** | 鲜肉 → 设置 →（tab）期初结转 | 链的起点。**不录 ⇒ 历史日的冷库偏低**，毛利不准 |
| 0.2 | 确认**大宗品项** | 鲜肉 → 大宗台账 → 结存与结转 | 佳乐(01)已装「板油/猪油」；富百家(00)没有（它的猪油是**每天零售**的，没有攒着卖酒店的大宗线）⇒ 需要时自己登记一个部位 |
| 0.3 | 确认**部位映射**齐了 | 鲜肉 → 设置 →（tab）部位 SKU 映射 | 盘点/搬台都按 (部位, 货号) 校验 ⇒ 缺映射会被拒 |

⚠️ **期初录完，它会同时进三个地方**：链（起点）、库存位置（冷库余额）、
结转队列（可领用/可结掉）⇒ 三处一致，门店在库存页看到的和报表说的才是同一个数。

### 期初的每一行是**三列**：重量 / 单价 / 总价

| 列 | 谁填 | 说明 |
|---|---|---|
| **期初重量 kg** | 门店 | 上线前冷库里这个部位还有多少 kg |
| **单价 元/kg** | 门店 | 这批货当时**多少钱一斤**（进价） |
| **总价 元** | **自动算** | 重量 × 单价，**不可填**（服务端也会再算一遍并落库） |

⚠️ **有货就必须填单价**（填了重量不填单价 ⇒ 会被拒，提示"没填单价"）：
期初是**上线前就在冷库里的货**，它的成本不在本系统的流水里
⇒ 单价 0 ⇒ 成本链第一天期初金额 0 ⇒ **那批货零成本** ⇒ 卖出去全是利润（**毛利虚高**）。

> 不知道当时多少钱？问老板/供应商那天的进价；实在不知道就按当天批发价估一个 ——
> **宁可给个大概的数，也别留 0**（0 = 白送）。

⚠️ **期初的生效日 = 冷库余额链的起点**：

- 你可以把生效日设成**上线那天**（比如 2026-10-01），**从第二天开始做第一期**；
- 那天（生效日）**不用补盘点单** —— 期初本身就是那天的基线
  （系统不会提示"10-01 未盘点"）；
- **生效日之前的日子在「每日作业」里选不到**（链还没开始，那几天的账算不出来）；
- 但**生效日之后每一天都要盘点** —— 漏一天，后面的冷库余额与毛利都会歪。

## 1. 每天的动作（照着「鲜肉 → 每日作业」页的顺序）

### ① 录猪（早上）

- 耳标号（没有也能填，**可空**）、**毛重**、**采购单价**、供应商、到场时间。
- 录完页面上会出现"已进猪"。

### ② 分割补录（切完就录）

- 每个部位切出多少 kg ⇒ 一个个部位录（**扫码补打条码**更快）。
- ⚠️ **货号要跟部位映射对得上**（切五花就选五花的货号）⇒ 选错了成本会摊到别的货号上。

### ③ 搬台（把昨天的货搬上猪肉台）

- 昨天日终盘点贴的**标签号** ⇒ 一个一个点（**整袋搬**）。
- ⚠️ 搬台要在**前一个营业日已盘点**之后才能做（没盘点 ⇒ 系统会拦，并告诉你要补哪天）。

### ④ 卖（POS 照常卖）

- 正常收银，**不用**在鲜肉域做什么。

### ⑤ 日终盘点（收摊后）

- 把**柜台上剩的**按 SKU 打包过秤 ⇒ 填重量 + **贴标签号**（一袋一个号，写人看得懂的）。
  - ⚠️ **贴标签号很重要**：第二天才能整袋搬上台，而且毛利能归到产出它的那几头猪。
  - ⚠️ **只盘柜台**：冷库里的货不在这张单上（冷库另列，只做展示）。
- **盘到 0 也要提交**（= 售罄）；**当天没进猪也没搬台**就提交空单（= 鲜肉休市）。

## 2. 大宗（水油攒着卖给酒店）

佳乐的水油(`03808`)是**每 9 天整一笔 400~870kg** ⇒ 它**不进柜台** ⇒ 盘点盘不到它。

| 步骤 | 做什么 | 在哪 |
|---|---|---|
| 2.1 | **手工补录**：冷库里这批水油有多少 kg | 鲜肉 → 大宗台账 → 结存与结转 → **手工补录**（品项选「板油/猪油」，填 kg） |
| 2.2 | 酒店来收 ⇒ **手工登记结算**：品项 / 数量 / 单价 / 结算日期 / 对方 | 鲜肉 → 大宗台账 → 统收结算 → 提交 |
⚠️ **`03808` 的 POS 销售不自动进鲜肉域**（那是"几百公斤一笔"的大宗货，
按零售算会全归到"当日某一头猪"头上 ⇒ 那头猪毛利虚高）⇒
**必须走上面 2.1 + 2.2 两步**，否则那笔收入会漏。

💡 **漏了也不会神不知鬼不觉**：那批货还挂在冷库里 ⇒ 结存页的「**可领用**」一直显示它
⇒ 数字对不上时，先看结存页：**可领用 ≠ 0 而你已结过 ⇒ 多结；可领用 > 0 而你已结过 ⇒ 少登记了**。

## 3. 我当场核对什么（只读，不动门店的数据）

跑一次只读诊断（打印门店当天的账）：

```powershell
cd F:\go\src\github.com\YunBright\deployer
$env:FM_DIAG_BRANCH="01"     # 或 00
go test ./tests/contract/ -run TestFreshMeatDiag -v -count=1
```

打印：期初结转 / 营业日状态 / 库存两位置 / 每一袋的归属与消耗 / 大宗结存 / 当日毛利 / 审计状态。

**我要核对的四件事**：

1. **冷库余额** == 门店实际冷库里的量（差 0）。
2. **每一袋**：产生日 / 重量 / 标签号 / 归到哪头猪 == 门店实际的袋子。
3. **当日毛利**：收入 − 成本 − 损耗 ≈ 手算的数。
4. **结存页的差额**（队列剩余 − 冷库余额）== 0 ⇒ 不为 0 = 有"位置混用"（零售/大宗扣的不是同一批货）。
