## 1. 为什么切（两页差在哪）

### 1.1 差的就是「搬出估算成本」这一项

| | 每日毛利看板**表头**（2026-11-03 起） | 长期毛利页每日行（**切之前**） |
|---|---|---|
| 成本 | 当日总支出(进猪+外采) **+ 搬出估算成本** − 盘点估算成本 | 当日总支出(进猪+外采) − 盘点估算成本 |
| 毛利 | 当日总收入 − 成本 | 当日总收入 − 成本 |

⇒ **只差「搬出估算成本」**（= Σ 搬上台 kg × 该部位**冷库移动加权成本**）。

## 2. 切完之后

### 2.1 每日行 = **当日口径**（与看板表头同一个数）

```
成本 = 当日总支出(进猪 + 外采) + 搬出估算成本 − 盘点估算成本
毛利 = 当日总收入 − 成本
毛利率 = 毛利 ÷ 当日总收入
```

⚠️ **三个守卫**（与看板**完全一致**）⇒ 算不出来就是算不出来 ⇒ 前端显示「—」，**绝不回落成 0**：

1. 当天没进货（进猪 + 外采）⇒ 没有采购均价 ⇒ 成本算不出来。
2. 没有**完整**日终盘点 ⇒ 期末猪肉台实盘拿不到 ⇒ 盘点估算成本算不出来。
3. 当天**没营收** ⇒ 毛利率没有分母。

### 2.2 **期间数不动**（仍是全店口径）

```
期间毛利 = 期间营收 − 期间采购(含外采) + (期末冷库量 − 期初冷库量) × 期间采购均价
```

⚠️ **每日之和 ≠ 期间毛利**（口径差，不是 bug）⇒ 两个数都保留，店长能自己核对差额从哪来：
差额来自**冷库结转** + **搬出估算成本** + 单日/期间采购均价的差异。

⚠️ **每日行 ≠ 看板的部位参考毛利之和**（两套口径）：
- 每日行 / 看板表头 = 「今天的现金账」；
- 看板部位参考毛利 = 「销量 × 部位成本单价」估的。
⇒ owner 明确要求：**门店不要拿部位行加总去核表头**。

## 3. 公式**只写一份**（为什么不可能漂移）

新增 `internal/fresh-meat/service/day_caliber_margin.go`：

```
dayCaliberMargin(ref ReferenceDayTotals, revenue, loadCost decimal.Decimal)
    (gm decimal.Decimal, pct float64, ok bool)
```

- **看板表头**（`cut_margin_dayend.go::applyReferenceMargin`）调它；
- **长期毛利每日行**（`long_term_margin.go::ComputeLongTermMargin`）也调它。

⇒ 两页的每日数**永远是同一个数** ⇒ 不会再出现「两页对不上」。
⚠️ `applyReferenceMargin` 的**行为逐位不变**（只是把公式搬进共用函数）。

⚠️ **搬出估算成本的口径两页同源**：
`cutRows` ↔ `mids` 是 **1:1** ⇒ 两页的 `Σ(搬上台 kg × 移动加权成本)` 完全同源。

## 5. 判别力实测（用例必须能区分「切了」与「没切」）

新增 `internal/fresh-meat/service/long_term_margin_day_caliber_test.go`（4 条）：

| 用例 | 锁什么 | 去掉实现后 |
|---|---|---|
| `DailyRowEqualsBoardHeader` | 每日行 **==** 看板表头（毛利 + 毛利率） | 退回旧口径 ⇒ **红** |
| `DailyRowSubtractsLoadCost` | 每日行 **== 旧口径 − 搬出估算成本**（手算 190 − 80 = 110） | 去掉搬出估算成本 ⇒ **红**（190 ≠ 110） |
| `NoRevenueMeansNoMargin` | 没营收 ⇒ **算不出来**（不是 0） | 去掉守卫③ ⇒ **红**（−320 ≠ 0） |
| `NoStocktakeMeansNoMargin` | 没完整盘点 ⇒ **算不出来** | 退回旧口径 ⇒ **红** |

⚠️ `DailyRowSubtractsLoadCost` 里有一条**前置断言**「搬出估算成本 > 0」：
搬上台 = 0 时新旧口径**恰好相等** ⇒ 用例会假绿 ⇒ 必须先把前置钉死。

**实测记录**（逐个把实现改坏再恢复）：

| 实验 | 改坏的地方 | 结果 |
|---|---|---|
| A | 长期毛利页退回旧口径 | **4 条全红** ✅ |
| B | 当日口径去掉「搬出估算成本」 | ② **红**（190≠110），①③④ 绿 ✅ |
| C | 去掉守卫③（当天没营收） | ③ **红**（−320≠0），①②④ 绿 ✅ |

⚠️ 实验 C 的开关**必须是运行期变量**：写 `if false` 会被 Go 编译器整个消掉
⇒ 实测会变成「没去掉实现」⇒ 结论是假的。
